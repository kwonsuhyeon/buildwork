# PRD: About 페이지 이력 정보 갱신

## 1. 개요

`src/app/about/page.tsx`의 학력·경력·프로젝트 이력 데이터를 2026년 9월 기준 최신 상태로 갱신한다.
모든 콘텐츠는 파일 상단의 상수 배열(`EDUCATION_ITEMS`, `CAREER_ITEMS`, `PROJECT_HISTORY`)에 정의되어 있으며,
이번 작업은 (1) 데이터 갱신과 (2) 경력 타임라인에 불릿 목록을 표시하기 위한 소규모 UI 확장으로 구성된다.

## 2. 목표

- 박사과정 재학 정보를 학력 섹션에 추가
- "AI 활용 특강" 항목에 대상 기관과 4개 강의 주제를 불릿 목록으로 노출
- 진행 중인 자문 프로젝트를 구체 사업명이 드러나지 않는 포괄적 표현으로 수정
- 2026년 신규 연구 프로젝트 2건을 프로젝트·자문 전체 이력에 추가
- 기존 레이아웃·스타일과 시각적 일관성 유지

## 4. 기능 요구사항

- FR-1: `EDUCATION_ITEMS` 맨 앞에 박사과정 항목을 추가하고, `thesis`가 빈 문자열이면 해당 줄을 렌더링하지 않는다.
- FR-2: `CAREER_ITEMS` 항목에 선택적 `items: string[]` 필드를 지원하고, 존재할 때만 `<ul>` 불릿 목록을 렌더링한다.
- FR-3: "AI 활용 특강" 항목의 `org`를 지정된 문구로 바꾸고 `items`에 4개 강의 주제를 넣는다.
- FR-4: "프로젝트 자문" 항목의 `description`을 `"AI·데이터 기반 직무·교육·역량평가 체계 및 기술 검토 자문"`으로 바꾼다.
- FR-5: `PROJECT_HISTORY`에 STEP 페르소나 연구, 대한상공회의소 수요조사 연구 2건을 최신순으로 삽입한다.
- FR-6: 모든 변경은 `src/app/about/page.tsx` 단일 파일 내에서 이루어진다.

## 5. 비목표 (범위 제외)

- 상단 "주요 프로젝트" 카드(`PROJECTS` 배열)에는 신규 항목을 추가하지 않는다 (공개 URL이 없음)
- 페이지 레이아웃·색상·섹션 구성 변경 없음
- Notion CMS 연동으로 이력 데이터를 옮기는 작업은 하지 않는다
- 다른 페이지(홈, insights, resources) 수정 없음

## 6. 디자인 고려사항

- 학력·경력 타임라인은 기존 `.timeline`, `.timeline-dot`, `.timeline-date`, `.timeline-title`, `.timeline-sub` 클래스를 그대로 사용
- 불릿 목록은 `timeline-sub`보다 살짝 작은 톤(`text-sm text-slate-600`)으로, 타임라인 점선과 정렬이 어긋나지 않도록 `pl-4` 이내로 들여쓴다
- 대외비 원칙: 프로젝트 이력에는 기관명만 표기하고 대시보드 링크는 공개하지 않는다 (신규 2건 모두 `url` 없음)

## 7. 기술 고려사항

- Next.js App Router 서버 컴포넌트, 데이터는 파일 내 상수이므로 빌드 외 추가 의존성 없음
- `CAREER_ITEMS`는 현재 타입 선언 없이 리터럴로 추론되므로, `items`를 일부 항목에만 넣으면 TS가 union 타입으로 추론한다. `item.items?.length` 옵셔널 체이닝으로 안전하게 접근하거나 명시적 타입을 선언한다.
- 검증 명령: `npm run lint`, `npx tsc --noEmit`, `npm run dev` 후 `/about` 확인

## 8. 성공 지표

- `/about` 페이지에서 학력 3건, 경력 3건(특강 불릿 4개 포함), 프로젝트·자문 이력 13건이 오류 없이 표시된다
- 프로젝트 자문 설명에 구체 사업명이 노출되지 않는다
- 린트·타입체크 통과, 기존 항목 표시 회귀 없음

## 9. 미결 사항

- 신규 프로젝트 2건의 `description` 문구는 제목에서 유추해 작성한 초안이므로 실제 수행 내용에 맞게 다듬을 필요가 있다
- STEP 프로젝트의 `org`를 "STEP"으로 할지 "한국기술교육대학교 온라인평생교육원(STEP)"으로 할지 최종 확인 필요
